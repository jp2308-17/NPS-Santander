## Hipótesis

Las variables de experiencia bancaria, uso de canales, antigüedad, número de productos y características demográficas permiten clasificar a los clientes en detractores, neutros y promotores con un desempeño superior a una clasificación aleatoria o basada únicamente en intuición.

Se espera que variables como satisfacción general, facilidad de resolución, confianza, rapidez de atención y calidad de los canales digitales estén asociadas con la categoría NPS del cliente.
